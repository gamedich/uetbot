## ✨ Возможности

### Для соискателей (Telegram / ВКонтакте / МАКС)
- 📝 16-шаговая анкета соискателя с FSM-валидацией и возможностью редактирования
- 🔒 Обязательное цифровое согласие на обработку ПДн (ст. 9 152-ФЗ)
- 📬 Вопросы специалисту кадров (`/ask`) с ответом прямо в бот
- 📊 Просмотр статуса своей анкеты (`/my`)
- 🗂 Выгрузка собственных данных (`/mydata`, ст. 14 152-ФЗ)
- 🚫 Отзыв согласия на обработку ПДн (`/revoke`, ст. 21 152-ФЗ)

### Для кадровой службы (HR-панель)
- 📥 Приём новых анкет в кадровый чат и ЛС с inline-кнопками управления
- 🔄 Смена статуса анкеты (Новая → В работе → Приглашён → Принят / Отклонён)
- 💬 Прямой Live-Chat с кандидатом в режиме реального времени
- 📅 Отправка индивидуальных приглашений на собеседование
- 📝 Заметки к каждой анкете, история обращений
- ⚙️ Управление вакансиями, HR-администраторами, кадровым чатом

### Для сотрудников депо (Личный кабинет)
- 🔐 Авторизация по номеру телефона через кадровый реестр
- 🤝 Реферальная программа «Приведи друга на предприятие»
- 📄 Заказ справок (2-НДФЛ, с места работы, копия трудовой книжки)
- 📞 Контакты подразделений МУП «УЭТ»

### Для технических администраторов
- 📊 Системный дашборд (`/tech`): аптайм, ОЗУ, статистика
- 🔧 Управление режимами PROD/TEST, технического обслуживания
- 🧪 Генерация тестовых анкет для отладки
- 💾 Горячие бэкапы БД, управление вакансиями

## 🏗 Архитектура

```
┌─────────────────────────────────────────────────────────────────┐
│                   Источники входящих сообщений                  │
│  Telegram Bot API  │  ВКонтакте Long Poll  │  МАКС Bot API      │
└────────┬───────────┴──────────┬────────────┴──────────┬─────────┘
         │                      │                        │
         ▼                      ▼                        ▼
┌─────────────────────────────────────────────────────────────────┐
│                    Диспетчер (aiogram 3.x)                      │
│  tech_router  →  hr_router  →  candidate_router  →  employee_router │
└─────────────────────────────────────────────────────────────────┘
         │
         ▼
┌─────────────────────────────────────────────────────────────────┐
│              Слой сервисов и хранения данных                    │
│  common.py (safe_send/answer, FSM)  │  keyboards.py             │
│  services/candidate_service.py      │  texts.py                 │
│  services/doc_generator.py          │                           │
├─────────────────────────────────────────────────────────────────┤
│              База данных SQLite WAL (dual DB)                   │
│  resumes.db (боевая)  │  resumes_test.db (тестовая, ID≥900000)  │
└─────────────────────────────────────────────────────────────────┘
```

**Шлюзы внешних мессенджеров** работают как фоновые asyncio-задачи:
- `gateways/vk_gateway.py` — VK Long Poll API
- `gateways/max_gateway.py` — МАКС / VK Teams Bot API

**Хранилище состояний FSM** — SQLite WAL (не In-Memory), гарантирует сохранение прогресса анкеты при перезапуске.

## 👥 Ролевая модель

| Роль | Доступ | Как назначить |
|------|--------|---------------|
| **Соискатель** | Анкета, /ask, /my, /mydata, /revoke | Любой пользователь |
| **Сотрудник депо** | Личный кабинет, реферальная программа, справки | Авторизация по телефону |

| **SuperAdmin** | Полный доступ ко всему | `SUPER_ADMIN_ID` в `.env` |

## 🚀 Быстрый старт

### Требования

- Python 3.11 или новее
- Linux (Ubuntu 22.04+ / Debian 12 рекомендуется для продакшна)
- Доступ к интернету (Telegram Bot API)

### 1. Клонировать репозиторий

```bash
git clone https://github.com/gamedich/uetbot.git
cd uetbot
git checkout beta   # рабочая ветка
```

### 2. Создать виртуальное окружение и установить зависимости

```bash
python3.11 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

### 3. Настроить конфигурацию

```bash
cp .env.example .env
nano .env   # или любой другой редактор
```

Обязательно заполнить:
- `TG_BOT_TOKEN` — токен от @BotFather
- `SUPER_ADMIN_ID` — ваш Telegram ID (получить командой `/id` у любого бота)

### 4. Запустить (режим разработки)

```bash
python bot.py
```

### 5. Автоматическое развёртывание (опционально)

```bash
python deploy.py
```

Скрипт `deploy.py` проверяет конфигурацию, создаёт необходимые директории и предлагает установить службу systemd.

## ⚙️ Развёртывание через systemd

### Создать файл службы

```bash
sudo nano /etc/systemd/system/uetbot.service
```

```ini
[Unit]
Description=UETBot — HR-сервис МУП Ульяновскэлектротранс
After=network.target
Wants=network-online.target

[Service]
Type=simple
User=uetbot
WorkingDirectory=/opt/uetbot
ExecStart=/opt/uetbot/venv/bin/python /opt/uetbot/bot.py
Restart=always
RestartSec=10
StandardOutput=journal
StandardError=journal
SyslogIdentifier=uetbot

# Ограничения безопасности
NoNewPrivileges=yes
PrivateTmp=yes
ProtectSystem=strict
ReadWritePaths=/opt/uetbot/data /opt/uetbot/logs /opt/uetbot/backups

[Install]
WantedBy=multi-user.target
```

### Активировать и запустить

```bash
sudo systemctl daemon-reload
sudo systemctl enable uetbot
sudo systemctl start uetbot

# Проверить статус
sudo systemctl status uetbot

# Просмотр логов в реальном времени
sudo journalctl -u uetbot -f
```

## 🛡 Соответствие 152-ФЗ «О персональных данных»

| Требование | Реализация |
|-----------|-----------|
| **Согласие на обработку ПДн** (ст. 9) | Обязательное согласие в шаге 1 анкеты, фиксация `consent_timestamp` |
| **Право на доступ** (ст. 14) | Команда `/mydata` — выгрузка всех данных пользователя |
| **Право на отзыв согласия** (ст. 21) | Команда `/revoke` — каскадное удаление ПДн из всех таблиц |
| **Срок хранения** (Приказ Росархива №236, ст. 441) | Автоудаление анкет через 3 года (`DATA_RETENTION_DAYS=1095`) |
| **Изоляция доступа в PROD** (ст. 6) | Технические администраторы исключены из получения ПДн |
| **Защита при передаче** (ст. 19) | Фото через RAM без записи на диск (`BufferedInputFile`) |
| **Маскирование в логах** | `ANONYMIZE_LOGS=1` — телефоны и Telegram ID скрыты |
| **Локализация** (ст. 18.1) | Данные хранятся только на серверах в РФ, внешние SaaS не используются |
| **Акт уничтожения** | `log_pdn_destruction()` — протокол уничтожения каждой анкеты |

> ⚠️ **Внимание**: Для соответствия законодательству убедитесь, что сервер расположен на территории РФ (ст. 18.1 152-ФЗ).

## 📁 Структура проекта

```
uetbot/
├── bot.py                  # Точка входа: диспетчер, роутеры, фоновые шлюзы
├── config.py               # Конфигурация через .env, AppConfig, validate_config()
├── common.py               # Глобальные объекты (bot, dp, db), safe_send/answer, FSM, middleware
├── database.py             # ResumeDB — SQLite WAL, все методы работы с данными
├── keyboards.py            # Все клавиатуры (inline + reply)
├── texts.py                # Тексты сообщений, форматирование карточек
│
├── handlers/
│   ├── candidate.py        # 16-шаговая анкета, /start, /help, /ask, /revoke, /mydata
│   ├── hr.py               # Кадровая панель, Live-Chat, управление анкетами
│   ├── tech.py             # Инженерная панель, дашборд, бэкапы, тесты
│   └── employee.py         # Личный кабинет сотрудника, реферальная программа
│
├── gateways/
│   ├── vk_gateway.py       # Шлюз ВКонтакте (Long Poll API)
│   └── max_gateway.py      # Шлюз МАКС / VK Teams
│
├── services/
│   ├── candidate_service.py    # Бизнес-логика обработки анкет
│   └── doc_generator.py        # Генерация кадровых документов (.docx)
│
├── data/                   # SQLite базы данных (в .gitignore)
├── logs/                   # Файлы логов (в .gitignore)
├── backups/                # Автоматические бэкапы БД (в .gitignore)
├── docs/                   # Документация и шаблоны документов
│
├── .env.example            # Шаблон конфигурации (все ключи с описаниями)
├── .gitignore              # Исключения git (секреты, ПДн, кэши)
├── .antigravityrules       # Правила проекта для Antigravity IDE
├── requirements.txt        # Зависимости Python
├── deploy.py               # Автоматическое развёртывание
└── run_tests.py            # Тестовый прогон функционала
```
