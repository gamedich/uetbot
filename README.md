
# Многоканальный HR-сервис МУП «Ульяновскэлектротранс» (v1.4.0 Stable)

[![Systemd](https://img.shields.io/badge/deploy-systemd_service-orange.svg)](https://systemd.io/)

Промышленный программный комплекс автоматизации рекрутинга, первичного анкетирования и оперативного взаимодействия с соискателями для Муниципального унитарного предприятия «Ульяновскэлектротранс» (г. Ульяновск).

Сервис поддерживает одновременную работу через **Telegram**, **ВКонтакте** и корпоративный мессенджер **МАКС (VK Teams / MyTeam)** с централизованной обработкой анкет и обращений в едином кадровом центре. Разработан в строгом соответствии с требованиями Федерального закона № 152-ФЗ «О персональных данных».

---

## 🌟 Ключевые возможности

* **16-шаговая профессиональная анкета соискателя:**
  * Пошаговый опросник с валидацией возраста (18+), ФИО, телефона (ввод или контакт).
  * Мультивыбор категорий водительских прав (`B`, `C`, `D`, `Tb`, `Tm`), стажа и уровня образования.
  * Учёт готовности к переезду, потребности в общежитии, медицинских ограничений и судимости (ст. 86 УК РФ).
  * Умный триггер: автоматическое предложение бесплатного обучения со стипендией для водительских вакансий без опыта.
  * Инлайн-меню точечного редактирования любого из 15 полей перед отправкой.
* **Полный контур соответствия 152-ФЗ РФ:**
  * Фиксация электронного согласия (`consent_timestamp`) до начала сбора данных.
  * `/mydata` — выгрузка персональных данных, хранящихся в информационной системе (ст. 14 152-ФЗ).
  * `/revoke` — безусловный отзыв согласия с моментальным уничтожением анкеты и формированием акта (ст. 21 152-ФЗ).
  * Изоляция персональных данных соискателей от технических специалистов в режиме `PROD`.
* **Персистентное хранение FSM (`SQLiteFSMStorage`):**
  * Все состояния и черновики анкет кандидатов сохраняются в таблице `fsm_storage` базы данных SQLite.
  * Анкеты не сбрасываются при перезапусках службы, обновлении кода или сбоях сети.
* **Двусторонний Live-Chat мост:**
  * Кадровик может открыть сквозной анонимный диалог с кандидатом прямо из карточки тикета.
  * Кандидат отвечает в Telegram, VK или МАКС — сообщения транслируются в кадровый чат и обратно в реальном времени.
* **Панель кадровой службы (`/admin`):**
  * Фильтрация анкет по статусам: «Новая», «В работе», «Приглашен», «Отказ», «Архив».
  * Выгрузка базы кандидатов в CSV/Excel по команде `/export`.
  * Быстрый набор номера соискателя, отправка персонализированных сообщений и текстовые заметки (`admin_note`).
  * Приглашение на собеседование с указанием точного времени, адреса и кабинета.
* **Инженерный центр управления (`/tech`, `/git`):**
  * Мониторинг здоровья систем, аптайма, оперативных логов (`/logs`) и состояния шлюзов.
  * Управление Git: обновление (`git pull`), мягкий откат (`git reset --hard HEAD~1`), возврат на актуальный коммит и переключение веток (`main` / `beta`).
  * Горячее создание (`/backup`) и восстановление (`/restore`) резервных копий SQLite в режиме WAL.
* **Экстренная техподдержка (`/support`, `/sos`):**
  * Прямая связь кандидатов с техническим инженером в обход кадрового чата при возникновении сбоев.

## 📁 Структура проекта

```text
├── bot.py                  # Точка входа, запуск поллинга и инициализация диспетчера
├── common.py               # Общие состояния FSM, синглтон БД, хранилище сессий, утилиты отправки
├── config.py               # Загрузка и валидация конфигурации из .env
├── database.py             # Слой работы с SQLite (WAL, миграции, индексы, бэкапы, 152-ФЗ)
├── deploy.py               # Скрипт автоматического развёртывания и генерации systemd-сервиса
├── texts.py                # Единый централизованный реестр текстов, шаблонов и карточек
├── keyboards.py            # Фабрики инлайн- и реплай-клавиатур интерфейса
├── handlers/
│   ├── candidate.py        # Диалоги с соискателями, опросник (16 шагов), /mydata, /revoke
│   ├── hr.py               # Кадровая панель, статусы, /export, заметки, Live-Chat
│   └── tech.py             # Инженерная панель, мониторинг, тесты, Git-контроль, бэкапы
├── gateways/
│   ├── vk_gateway.py       # Асинхронный шлюз ВКонтакте (Long Poll API)
│   └── max_gateway.py      # Шлюз корпоративного мессенджера МАКС (MyTeam Bot API)
├── backups/                # Локальное хранилище горячих резервных копий SQLite
└── data/                   # Директория для вакансий (vacancies.json)
