Промышленный программный комплекс автоматизации рекрутинга, первичного анкетирования и оперативного взаимодействия с соискателями для **Муниципального унитарного предприятия «Ульяновскэлектротранс»** (г. Ульяновск).

Сервис обеспечивает одновременный приём анкет и обращений через **Telegram**, **ВКонтакте** и корпоративный мессенджер **МАКС (VK Teams / MyTeam)** с централизованной обработкой в едином кадровом центре. Разработан в строгом соответствии с требованиями Федерального закона № 152-ФЗ «О персональных данных».

## 🌟 Ключевые возможности

### 👤 1. Для соискателей (Кандидаты)
* **16-шаговая профессиональная анкета:**
  * Валидация ФИО, возраста (18+) и номера телефона (через кнопку контакта или ручной ввод с маской `+7`).
  * Мультивыбор категорий водительских прав (`A`, `B`, `C`, `D`, `E`, `Трамвай`, `Троллейбус`).
  * Фиксация стажа, уровня образования и конкретного учебного заведения.
  * Учёт готовности к переезду в г. Ульяновск, потребности в общежитии, сменного графика (2/2), мед. противопоказаний и судимости (ст. 86 УК РФ).
  * **Умный триггер бесплатного обучения:** автоматическое предложение бесплатного обучения со стипендией при выборе водительских специальностей без опыта.
  * Инлайн-меню проверки и точечного редактирования любого из 15 полей перед отправкой.
* **Полный контур соответствия 152-ФЗ РФ:**
  * Получение электронного согласия соискателя (`consent_timestamp`) на шаге 0 до начала сбора данных.
  * `/mydata` — прозрачная выгрузка персональных данных соискателя по ст. 14 152-ФЗ.
  * `/revoke` — отзыв согласия с моментальным уничтожением анкеты и формированием акта (ст. 21 152-ФЗ).
* **Раздел «Моя анкета» (`/my`):** просмотр текущего статуса рассмотрения заявки («Новая», «В работе», «Приглашен», «Отказ»).
* **Вопросы в отдел кадров (`/ask`):** отправка вопросов кадровикам с защитой от спама (антифлуд-кулдаун).
* **Справочник предприятия (FAQ):** условия труда, общежитие, льготный пенсионный стаж водителей, контакты депо.
* **Экстренная техподдержка (`/support`):** прямая связь с дежурным инженером при технических неполадках.

### 📋 2. Для кадровой службы (HR)
* **Кадровая панель управления (`/admin`):**
  * Сводная аналитика по воронке подбора в реальном времени.
  * Фильтрация анкет по статусам: «Новая», «В работе», «Приглашен», «Отказ», «Архив».
  * Выгрузка базы соискателей в формате CSV/Excel (`/export`).
* **Авто-управление доступом участников кадрового чата:**
  * **Вход в группу:** при добавлении сотрудника в группу отдела кадров бот автоматически выдаёт ему роль HR в базе и приветствует по никнейму (`@username`).
  * **Выход из группы:** при выходе или удалении сотрудника из группы роль HR моментально отзывается, и доступ к `/admin` закрывается.
  * **Двухсторонняя синхронизация (`/sync`):** в 1 клик сверяет состав группы с базой данных — выдаёт права новым сотрудникам и снимает у тех, кто покинул чат.
  * **Быстрый кик (`/kick`):** администратор группы может ответить командой `/kick` на сообщение любого сотрудника для его удаления из чата и отзыва прав.
* **Карточка соискателя в кадровом чате:**
  * Полный блочный отчёт по всем 16 пунктам анкеты.
  * Смена статусов в 1 клик с моментальным авто-уведомлением соискателя.
  * Персональное приглашение на собеседование с указанием точной даты, времени и кабинета.
  * Служебные заметки кадровика к анкете (`admin_note`).
* **Сквозной Live-Chat мост:**
  * Кадровик может нажать кнопку «🟢 Начать прямой диалог» и общаться с соискателем в реальном времени через бота (соискатель отвечает в TG, VK или МАКС, а кадровик пишет прямо в группе или ЛС).
* **Централизованное управление уведомлениями в ЛС:**
  * По умолчанию уведомления приходят в общий кадровый чат (чтобы не забивать лички сотрудников).
  * Возможность включить/выключить персональные уведомления в ЛС в `/admin`.

### 🛠 3. Для технических инженеров (Tech / SuperAdmin)
* **Инженерный дашборд (`/tech`):**
  * Мониторинг аптайма, здоровья SQLite, счетчика ошибок и статуса шлюзов (Telegram, VK, MAX).
  * Переключение режима среды: `PROD` (строгий 152-ФЗ, лимиты, антифлуд) ↔ `TEST` (без ограничений).
  * Режим обслуживания (`ТО`): временная приостановка приема анкет на время регламентных работ.
* **Управление командой (`/admins`):**
  * Просмотр всех администраторов с отображением `@username` и ФИО.
  * Назначение новых кадровиков (`/add_hr`) и инженеров (`/add_tech`).
  * Безопасный отзыв прав (`/del_admin`).
* **Автоматическое резервное копирование:**
  * Фоновый сервис делает горячий слепок SQLite через Backup API каждые 24 часа.
  * Авто-очистка: сохраняются 7 последних свежих копий.
  * Меню бэкапов (`/backups`): скачивание `.db` файла прямо в Telegram и безопасный откат базы (`/restore`).
* **Панель тестов (`/tests`):**
  * Генератор реалистичных тестовых анкет из Telegram и VK со всеми 16 шагами.
  * Симуляция вопросов соискателей.
  * Пинг шлюза ВКонтакте (`/check_vk`).
  * Быстрый сброс тестовых анкет администратора (`/reset`).
* **Управление версиями и службой (`/git`):**
  * Просмотр текущей ветки, статуса файлов и последнего коммита.
  * Стягивание обновлений (`git pull`) и откат на коммит назад (`git rollback`) в 1 клик.
  * Безопасный перезапуск службы `systemctl restart uet_bot`.

## 🏗 Архитектура проекта

Проект выстроен по принципам модульности, слабой связанности (Loose Coupling) и строгой типизации:

```text
├── bot.py                  # Точка входа: Bot, Dispatcher, фоновые задачи (VK, MAX, автобэкап)
├── config.py               # Типизированный AppConfig, загрузка .env, маскирование секретов
├── database.py             # SQLite класс ResumeDB: WAL-режим, CRUD, FSM-таблицы, 152-ФЗ
├── common.py               # safe_send/safe_answer, AiohttpSession(20s), FSM, роли, метрики
├── texts.py                # Текстовая карта бота (16 шагов, шаблоны карточек, FAQ, справка)
├── keyboards.py            # Фабрики Inline- и Reply-клавиатур (адаптивная строчная сетка)
├── deploy.py               # Генератор systemd-юнита и автоматический развертыватель
├── requirements.txt        # Список зависимостей Python
│
├── handlers/               # Модули обработчиков сообщений и событий
│   ├── __init__.py         # Экспорт роутеров (tech, hr, candidate)
│   ├── candidate.py        # Воронка соискателя (меню, 16 шагов, FSM, валидация)
│   ├── hr.py               # Кадровая служба (/admin, тикеты, /sync, /kick, заметки)
│   └── tech.py             # Инженерия (/tech, /tests, /backups, /admins, /git)
│
├── gateways/               # Внешние шлюзы каналов связи
│   ├── vk_gateway.py       # Двусторонний шлюз сообщений и фото ВКонтакте (Long Poll)
│   └── max_gateway.py      # Шлюз корпоративного мессенджера МАКС (MyTeam API)
│
├── data/                   # Автосоздаваемый каталог баз данных SQLite (*.db)
├── logs/                   # Автосоздаваемый каталог логов (bot.log)
└── backups/                # Автосоздаваемый каталог резервных копий БД
```

## 🚀 Установка и запуск

### 1. Системные требования
* **ОС:** Linux (Ubuntu 20.04+, Debian 11+, Rocky Linux / CentOS 8+) или Windows Server
* **Python:** 3.11 или новее
* **SQLite:** 3.35+ (встроен в Python)

### 2. Клонирование и настройка окружения
```bash
# Клонирование репозитория
git clone https://github.com/your-org/uet_bot.git
cd uet_bot

# Создание и активация виртуального окружения
python3 -m venv venv
source venv/bin/activate

# Установка зависимостей
pip install --upgrade pip
pip install -r requirements.txt
```

### 3. Настройка переменных окружения (`.env`)
Создайте файл `.env` на основе шаблона:
```bash
cp .env.example .env
nano .env
```

Заполните обязательные параметры:
```ini
# Режим среды (PROD для штатной работы, TEST для отладки)
ENVIRONMENT=PROD
BOT_VERSION=1.5.0

# Токен Telegram-бота (получен у @BotFather)
TG_BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrSTUvwxyz

# Telegram ID Главного администратора (узнать свой ID: отправьте боту /id)
SUPER_ADMIN_ID=823092891

# ID группы отдела кадров (со знаком минус, например -1003875480349)
HR_GROUP_ID=-1003875480349

# Контакты отдела кадров предприятия
HR_PHONE=+7 (8422) 58-46-60
HR_ADDRESS=г. Ульяновск, ул. Гончарова, 2
HR_SCHEDULE=пн-пт 08:00–17:00 (перерыв 12:00–13:00)
COOLDOWN_SECONDS=1200

# Интеграция ВКонтакте (опционально)
VK_GROUP_TOKEN=vk1.a.your_token_here
VK_GROUP_ID=123456789

# Интеграция МАКС / MyTeam (опционально)
MAX_BOT_TOKEN=001.your_max_token_here
MAX_API_BASE=https://api.myteam.mail.ru/bot/v1
```

### 4. Развертывание в качестве службы systemd (Linux)
Для автоматического запуска при перезагрузке сервера:
```bash
# Запуск мастера развертывания
sudo python3 deploy.py
```
Либо вручную создайте файл `/etc/systemd/system/uet_bot.service`:
```ini
[Unit]
Description=МУП Ульяновскэлектротранс HR Telegram Bot
After=network.target

[Service]
Type=simple
User=root
WorkingDirectory=/root/uetbot
ExecStart=/root/uetbot/venv/bin/python3 /root/uetbot/bot.py
Restart=always
RestartSec=5
StandardOutput=journal
StandardError=journal

[Install]
WantedBy=multi-user.target
```

Управление службой:
```bash
systemctl daemon-reload
systemctl enable uet_bot
systemctl start uet_bot

# Проверка статуса и просмотр логов
systemctl status uet_bot
journalctl -u uet_bot -f
```

## ⚖️ Безопасность и соответствие 152-ФЗ РФ
1. **База данных размещена локально:** все файлы SQLite (`resumes.db`) хранятся на защищенном сервере предприятия на территории Российской Федерации.
2. **Изоляция в режиме PROD:** разработчики и технические инженеры не получают персональные данные кандидатов в ЛС (доступ имеют только авторизованные сотрудники отдела кадров).
3. **Автоматический аудит:** перед любым удалением анкеты автоматически формируется горячая резервная копия базы.
4. **Маскирование секретов:** токен Telegram и внешние ключи не отображаются в открытом виде в логах и диагностике.
