# Бот по подбору персонала МУП «Ульяновскэлектротранс» (Modular Architecture)

Промышленный многоканальный сервис для автоматизации рекрутинга и обработки обращений соискателей через Telegram, ВКонтакте и корпоративный мессенджер МАКС (MyTeam / VK Teams). Разработан в соответствии с требованиями Федерального закона № 152-ФЗ «О персональных данных».

---

## 🏛 Модульная архитектура проекта (Layered Architecture)

Система разделена на независимые слои, исключающие взаимные сбои и ошибки отступов при обновлении:

```text
uetbot/
├── bot.py                  # Главная точка входа (~50 строк): запуск, роутеры, фоновые шлюзы
├── common.py               # Общие состояния FSM, экземпляры bot/dp/db, системные метрики
├── keyboards.py            # Все инлайн- и реплай-клавиатуры Telegram
├── config.py               # Загрузка и строгая валидация .env
├── database.py             # СУБД SQLite (WAL-режим, составные индексы, горячий бэкап)
│
├── handlers/               # Обработчики Telegram по ролям (aiogram Router)
│   ├── candidate.py        # Соискатели: /start, /apply, анкета (FSM), FAQ, «Задать вопрос»
│   ├── hr.py               # Кадровая служба: /admin, карточки анкет, решения, прямой диалог
│   └── tech.py             # Инженерная панель: /tech, /backup, /admins, метрики, режим PROD/TEST
│
├── gateways/               # Внешние мессенджеры (шлюзы)
│   ├── vk_gateway.py       # Автономный Long Poll ВКонтакте, анкетирование и живой чат
│   └── max_gateway.py      # Long Poll корпоративного мессенджера МАКС / VK Teams
│
├── docs/                   # Документация проекта (Трек В)
│   ├── prd.md              # Product Requirements Document (PRD)
│   ├── glossary.md         # Глоссарий предметной области
│   └── adr/                # Архитектурные решения (ADR 001 - 003)
│
├── run_bot.bat             # Единый запуск (python bot.py)
├── install_bot.bat         # Первичная установка виртуального окружения
└── requirements.txt
```

---

## 🚀 Запуск и эксплуатация

1. **Запуск:** запустите `run_bot.bat` (или команду `python bot.py`).
   * Главный файл `bot.py` неизменен — при редактировании вакансий, текстов или логики меняются только соответствующие файлы в `handlers/` или `gateways/`.
2. **Интеграция с ВКонтакте:**
   * В `.env` укажите `VK_GROUP_TOKEN` и `VK_GROUP_ID`.
   * Шлюз `gateways/vk_gateway.py` запустится автоматически в фоне.
3. **Мост прямого диалога (Live Chat):**
   * При нажатии кадровиком кнопки `🟢 Начать прямой диалог` в Telegram, все входящие сообщения соискателя из Telegram или ВКонтакте пересылаются кадровику, а ответы кадровика уходят обратно кандидату.
