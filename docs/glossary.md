# Глоссарий проекта (Glossary)

| № | Термин | Определение |
|---|--------|-------------|
| 1 | **FSM (Finite State Machine)** | Машина состояний, управляющая последовательными шагами диалога с пользователем. |
| 2 | **Long Polling** | Метод получения обновлений от серверов мессенджера путем удержания длительного входящего HTTP-соединения. |
| 3 | **Webhook** | Механизм оповещения системы о событиях через отправку входящих HTTP POST-запросов на внешний URL сервиса. |
| 4 | **Соискатель** | Пользователь бота, проходящий анкетирование с целью трудоустройства. |
| 5 | **Анкета** | Набор структурированных полей с персональными данными кандидата (ФИО, возраст, телефон, желаемая вакансия и т.д.). |
| 6 | **Рекрутер** | Специалист отдела кадров, получающий уведомления и финальные данные анкеты кандидата для обработки. |
| 7 | **Мультиканальность** | Архитектурная способность системы одновременно и согласованно работать через несколько платформ (Telegram, VK, MAX). |
| 8 | **Event Loop** | Цикл событий в асинхронной среде `asyncio`, управляющий диспетчеризацией неблокирующих задач. |
| 9 | **aiogram** | Асинхронный фреймворк на Python для взаимодействия с Telegram Bot API. |
| 10 | **vkbottle** | Асинхронный модульный фреймворк для разработки ботов ВКонтакте. |
| 11 | **SQLite** | Встраиваемая реляционная база данных, хранящая всю информацию в едином локальном файле. |
| 12 | **aiosqlite** | Асинхронная библиотека-драйвер для работы с базой данных SQLite в неблокирующем режиме. |
| 13 | **Валидация** | Процесс проверки введенных пользователем данных на корректность и соответствие ожидаемому формату (номер телефона, диапазон возраста). |
| 14 | **Переменные окружения (`.env`)** | Механизм передачи конфиденциальных конфигураций и токенов приложению вне репозитория кода. |
| 15 | **Handler (Обработчик)** | Функция в коде, принимающая входящее событие (сообщение, нажатие кнопки) и возвращающая ответ пользователю. |
