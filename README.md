## 📌 О проекте

**АИС «Рекрутинг-Сервис»** — промышленное мультиканальное решение для автоматизации первичного подбора персонала, обработки обращений соискателей и оперативного информирования пассажиров городского электротранспорта г. Ульяновска.

Система объединяет соискателей из **Telegram** и **ВКонтакте** в единую защищенную диспетчерскую панель отдела кадров, обеспечивая строгую юридическую чистоту сбора данных в соответствии с **Федеральным законом № 152-ФЗ «О персональных данных»**.

---

## ✨ Ключевые возможности

* 📲 **Мультиканальный приём анкет:** Единая воронка кандидатов из Telegram и ВКонтакте (автономный Long Poll шлюз).
* 🔒 **Строгий комплаенс 152-ФЗ:** Обязательная электронная фиксация согласий кандидатов с метками времени до начала ввода ПДн.
* 🛡 **Интеллектуальная валидация ввода:** Проверка телефонных номеров РФ (+7/8, DEF-коды), фильтрация мусорных ФИО и спам-сообщений.
* 💬 **Мост прямого диалога (Live Chat):** Операторы отдела кадров общаются с соискателями прямо через интерфейс Telegram, ответ уходит кандидату в исходный мессенджер.
* 📚 **Автоответчик и база регламентов (`notes.json`):** Мгновенная реакция по ключевым фразам в чатах пассажиров (задержки, поломки, стоп-лист, расписание, вещи) с защитой от флуда.
* 📊 **Кадровая аналитика:** Мгновенный экспорт базы кандидатов и обращений в Excel (`.xlsx`) по кнопке или команде.
* 💾 **Отказоустойчивость:** База данных SQLite в режиме **WAL (Write-Ahead Logging)**, автоматические горячие бэкапы при изменениях.

## 🏛 Модульная архитектура (Layered Architecture)

```text
uetbot/
├── bot.py                  # Точка входа: жизненный цикл, регистрация роутеров, шлюзы
├── config.py               # Загрузка и строгая валидация конфигурации .env
├── common.py               # Общие объекты (bot, dp, db), FSM, валидаторы и метрики
├── database.py             # СУБД SQLite (WAL-режим, миграции, составные индексы, бэкапы)
├── keyboards.py            # Фабрики Inline- и Reply-клавиатур интерфейса
├── texts.py                # Единый репозиторий системных текстов и шаблонов
│
├── data/                   # Постоянное хранилище
│   ├── resumes.db          # Реляционная база соискателей и настроек
│   └── notes.json          # База регламентов предприятия и триггеров автоответчика
│
├── handlers/               # Модули бизнес-логики по ролям пользователей
│   ├── candidate.py        # Сценарии соискателя: опрос FSM, FAQ, подача обращений
│   ├── hr.py               # Панель отдела кадров: карточки тикетов, экспорт Excel
│   ├── notes.py            # Модуль регламентов: /note, #хештеги, автоответчик в беседах
│   └── tech.py             # Инженерная панель: /tech, режим ТО, бэкапы, логи
│
├── gateways/               # Независимые внешние мессенджеры
│   ├── vk_gateway.py       # Автономный шлюз ВКонтакте (Long Poll API)
│   └── max_gateway.py      # Шлюз корпоративного мессенджера МАКС / VK Teams
│
├── docs/                   # Проектная и архитектурная документация
│   ├── tz.md               # Техническое задание (ГОСТ 34.602-2020)
│   ├── prd.md              # Product Requirements Document
│   ├── glossary.md         # Глоссарий предметной области
│   └── CHANGELOG.md        # История версий и релизов (SemVer / Keep a Changelog)
│
├── backups/                # Горячие резервные копии базы данных (*.db)
└── requirements.txt        # Зависимости Python
