## 🚀 Ключевые возможности

### 👤 Для соискателей (Telegram / ВКонтакте / МАКС)
* 📝 **Пошаговая анкета кандидата:** Полная валидация возраста (18+), телефона (+7/8), ФИО, водительского удостоверения и профильного опыта.
* 🛡 **Обязательное цифровое согласие:** Фиксация согласия на обработку ПДн (ст. 9 152-ФЗ РФ) с фиксацией метки времени.
* 💬 **Прямой диалог и поддержка:** Заказ обратной связи (`/ask`) и двухсторонний защищённый чат с кадровиком через бота.
* 📅 **Умное приглашение на собеседование:** Выбор депо, удобной даты/времени из рабочих слотов и интерактивное подтверждение явки.
* 🔒 **Право на забвение:** Просмотр своей анкеты (`/my`), выгрузка данных (`/mydata`, ст. 14 152-ФЗ) и полный отзыв ПДн (`/revoke`, ст. 21 152-ФЗ) с генерацией акта об уничтожении.

### 👔 Для кадровой службы (HR-служба)
* 📥 **Маршрутизация анкет:** Мгновенная доставка резюме в кадровый суперчат `HR_GROUP_ID` и личные сообщения HR-специалистов.
* 🔍 **Скоринг безопасности (ст. 328.1 ТК РФ):** Автоматическая проверка ограничений на работу в общественном транспорте, наличия водительских категорий и черных списков.
* 📊 **Кадровая панель (`/hr`):** Воронка найма (Новые → В работе → Собеседование → Принят / Отклонён), просмотр списков, карточек и заметок.
* 💬 **Live-Chat с кандидатом:** Прямая переписка с соискателем через интерфейс бота с пересылкой текстовых сообщений и фото.
* 📈 **Экспорт в Excel (`/export`):** Формирование официального кадрового отчёта с разделением на активные резюме и архив.

### 🛠 Для технических специалистов (`/tech`)
* ⚡ **Системный мониторинг:** Аптайм, потребление ОЗУ, размер баз данных, статус внешних шлюзов.
* 🧪 **Двухконтурная БД:** Мгновенное переключение между боевой (`resumes.db`) и изолированной тестовой базой (`resumes_test.db`, анкеты `#900000+`).
* 💾 **Автобэкапы:** Ежесуточное резервное копирование SQLite WAL с ротацией (хранение 7 последних копий).
* 🔄 **Git-управление:** Меню обновления и рестарта через интерфейс Telegram.

## ⚙️ Сервисный слой

Бизнес-логика вынесена из обработчиков Telegram в сервисы:

1. **`services/compliance_service.py`**:
   - Проверка по **ст. 328.1 ТК РФ** (ограничения на управление общественным транспортом при судимостях за тяжкие/особо тяжкие преступления).
   - Валидация водительских категорий под выбранную вакансию (трамвай / троллейбус / автобус).
   - Проверка глобального ЧС (Blacklist) и кулдаунов повторной подачи заявок.
2. **`services/interview_service.py`**:
   - Автоматическая генерация доступных таймслотов (пн-пт, 09:00 - 16:30) с учётом обеда кадровой службы.
   - Поддержка площадок МУП «Ульяновскэлектротранс»:
     - *Северное трамвайное депо № 1* (ул. Радищева, 144а)
     - *Засвияжское трамвайное депо № 2* (Московское шоссе, 1б)
     - *Заволжский троллейбусный парк № 3* (ул. Брестская, 78)
   - Контроль явки и подтверждения кандидатом.
3. **`services/candidate_service.py`**:
   - Инкапсулированная регистрация соискателей в БД, изоляция тестовых номеров (`#900000+`).
   - Уничтожение ПДн по 152-ФЗ с логированием в `destruction_logs`.
4. **`services/doc_generator.py`**:
   - Формирование официального акта об уничтожении ПДн в формате `.docx` по требованиям Роскомнадзора (Приказ № 179).

## 🌐 Веб-панель управления и Telegram Mini App

Бот включает встроенный легковесный веб-сервер на `aiohttp.web`, не требующий сторонних тяжёлых фреймворков:

* **Адрес веб-панели:** `https://213.226.124.135.sslip.io/` (защищённый HTTPS / Nginx reverse proxy на `127.0.0.1:8080`)
* **API Endpoints:**
  - `GET /api/stats` — метрики воронки (всего, новые, в работе, наняты, отклонены, обращения).
  - `GET /api/candidates` — реестр последних кандидатов с фильтрацией.
  - `GET /api/health` — мониторинг работоспособности сервиса.
* **Telegram Mini App (TMA):** 
  Открывается как полноценный WebApp прямо внутри Telegram (параметр `WEB_APP_URL` в `.env`).

## 🗄 Базы данных и изоляция путей

Все базы данных хранятся **строго внутри каталога `data/`**:
* **`data/resumes.db`** — боевая база данных кандидатов.
* **`data/resumes_test.db`** — изолированная тестовая база для безопасной отладки.

### Оптимизации SQLite:
* Журналирование **WAL (Write-Ahead Logging)** — чтение не блокирует запись.
* `PRAGMA synchronous=NORMAL;` — защита от повреждения данных при сбоях.
* `PRAGMA cache_size=-64000;` — выделение 64 МБ оперативной памяти под кэш страниц.
* `PRAGMA busy_timeout=30000;` — защита от ошибок `database is locked`.

## 🛡 Безопасность и 152-ФЗ

1. **Изоляция ролей (ст. 6 152-ФЗ):** Технические администраторы лишены прямого доступа к персональным данным соискателей в интерфейсе.
2. **Фиксация согласия (ст. 9 152-ФЗ):** Дата, время и идентификатор согласия соискателя фиксируются в таблице `user_consents`.
3. **Право на отзыв (ст. 21 152-ФЗ):** По команде `/revoke` персональные данные кандидата безвозвратно удаляются из активной базы, запись вносится в реестр уничтожения с автогенерацией Акта.
4. **Защита от спама:** Настраиваемый кулдаун между подачами анкет (по умолчанию 20 минут).

## 👥 Ролевая модель

| Роль | Права | Способ назначения |
|---|---|---|
| **Соискатель** | Заполнение анкеты, статус (`/my`), выгрузка (`/mydata`), отзыв ПДн (`/revoke`), вопрос кадровику (`/ask`). | Любой пользователь |
| **HR-специалист** | Кадровая панель (`/hr`), просмотр анкет, Live-Chat, приглашения на собеседование, экспорт Excel. | Назначение SuperAdmin (`/add_hr`) или добавление в кадровый чат |
| **Технический администратор** | Системный дашборд (`/tech`), очистка кэша, запуск бэкапов, тестовая база, Git-меню. | Указание в `.env` (`TECH_ADMIN_ID`) |
| **Главный администратор (SuperAdmin)** | Полный контроль над системой, управление ролями, беззвучный режим для HR. | Указание в `.env` (`SUPER_ADMIN_ID`) |

## 🚀 Установка и запуск

### 1. Клонирование и окружение
```bash
git clone https://github.com/gamedich/uetbot.git
cd uetbot

python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

### 2. Настройка конфигурации
```bash
cp .env.example .env
nano .env
```

### 3. Запуск как системный сервис (systemd)
Создайте `/etc/systemd/system/uet_bot.service`:
```ini
[Unit]
Description=Telegram/VK/MAX Bot for MUP Ulyanovskelektrotrans
After=network.target

[Service]
Type=simple
User=root
WorkingDirectory=/root/uetbot
ExecStart=/root/uetbot/venv/bin/python /root/uetbot/bot.py
Restart=always
RestartSec=5
StandardOutput=journal
StandardError=journal

[Install]
WantedBy=multi-user.target
```

Управление сервисом:
```bash
systemctl daemon-reload
systemctl enable uet_bot
systemctl restart uet_bot
systemctl status uet_bot
```
