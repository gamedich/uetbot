# ADR 001: Выбор языка программирования и фреймворков

* **Статус:** Accepted
* **Дата:** 2026-09-16
* **Автор:** Крючков И. К.

## Контекст
Разработка мультиканального чат-бота для рекрутинга с поддержкой пошаговых опросов (FSM) и высокой отзывчивостью под нерегулярные пиковые нагрузки.

## Рассмотренные альтернативы
1. **Python + aiogram / vkbottle**
2. **Node.js + Telegraf / vk-io**
3. **C# + Telegram.Bot**

## Решение
Выбран стек **Python 3.10+** с асинхронными библиотеками **aiogram 3.x** и **vkbottle** (а также нативным асинхронным клиентом VK Long Poll).

## Обоснование
Python предоставляет готовые абстракции для машин состояний (FSM) из коробки, обладает развитой экосистемой асинхронных библиотек для работы с API мессенджеров и позволяет быстро модифицировать структуру вопросов без повторной компиляции проекта.

## Последствия
* **Положительные:**
  * Быстрый старт и реализация бизнес-логики FSM.
  * Асинхронная обработка десятков одновременных диалогов в одном потоке без блокировок Event Loop.
* **Отрицательные:**
  * Необходимость строгого контроля типов (через type hints / mypy) и изоляции блокирующих дисковых вызовов в пул потоков (`asyncio.to_thread`).
